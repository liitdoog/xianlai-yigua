# 闲来一卦 · 安卓网页版

微信小程序的轻量化网页版。纯 HTML 单文件，无任何依赖、无网络请求，**完全离线可用**。

功能：

- **六爻起卦**：灵感源自《易经》六十四卦，随缘一触起卦。
- **生辰八字**：输入出生信息（性别 / 公历农历 / 年月日 / 时辰）排四柱命盘，分析日主强弱、喜用神、格局、性格与事业财运感情，参考陆致极《命运的求索》之子平框架。
- **运势推演**：基于已排八字查看**每日运势**（当日干支 + 宜忌 + 吉凶评分）、**每月运势**与**流年**，均可前后翻页，并支持综合 / 事业 / 财运 / 情感 / 健康侧重切换。
- **双人合盘**：输入两人出生信息，按关系类型（情侣 / 事业伙伴 / 上下级 / 综合）分析八字合不合，输出合盘评分、分项吉凶详解与相处建议。

## 在安卓手机上使用

### 方式一：单文件直接打开（最简单）

把 `web/` 里的 **`index.html`** 这一个文件发送到手机（微信文件传输助手、QQ、数据线拷贝均可），在手机上点击用浏览器打开即可使用。起卦、排盘、看运势、分享全部正常。

> 用微信打开时，建议右上角「···」→「在浏览器打开」，体验更佳（微信内置浏览器不支持部分网页能力）。

### 方式二：托管到服务器（推荐，永久可用）

把整个 `web/` 文件夹上传到任意静态网站空间（如腾讯云 COS 静态网站、GitHub Pages、Cloudflare Pages 等），访问对应网址即可。这样亲戚朋友都能通过网址访问，且支持离线与安装。

本地先看效果可用任意静态服务器：

```bash
# 任选其一，在 web/ 目录下执行
npx serve .
python -m http.server 8000
```

### 方式三：添加到主屏幕（类 App 体验）

当通过 **http(s) 托管地址**访问时，安卓 Chrome 会出现「添加到主屏幕」/「安装」提示（或点右上角菜单 → 添加到主屏幕）。安装后：

- 桌面出现「闲来一卦」图标（复用小程序头像）
- 点击直接全屏启动，无浏览器地址栏
- 首次访问后**完全离线可用**（Service Worker 已缓存全部文件）

> 只有托管在 http(s) 地址时才支持安装；`file://` 直接打开不支持此能力，属浏览器正常限制。

## 与本项目的关系

- 本目录是**独立**的网页版，**不影响**微信小程序的编译与发布。
- `index.html` 内的六十四卦数据与起卦算法**逐字移植**自小程序的 `data/`、`utils/`。**差异**：网页版在种子中额外混入了系统真随机数（Web Crypto API），因此网页版结果**不可复现、与小程序不保证一致**——这是网页版的随机性增强。
- **生辰八字部分为网页版独有**，小程序暂无此功能，因此不存在同步问题。
- **改动小程序数据后**：若希望网页版同步，需把 `data/hexagrams.js`、`data/trigrams.js`、`utils/*.js` 的改动同步到 `index.html` 中对应的内联代码段（段首有「来源：小程序 …」注释标记）。

## 注意事项

- 网页版「分享」是**文本分享**（系统分享面板 / 复制文案），非小程序那种带图卡片，这是网页能力所限。
- 分享文案在有结果时会带上卦名与变卦，与小程序分享文案保持一致。
- 生辰八字按**北京时间**、以**23 点换日**为界排盘（晚子时按次日计日）；出生信息仅保存在本机浏览器（localStorage），不会上传。
- 农历换算覆盖 1900–2100 年，含闰月。
- 命理内容参考陆致极《命运的求索》之子平框架，与六爻卦辞一样，仅供文化欣赏与娱乐参考，不构成任何决策建议。
